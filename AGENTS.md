# AGENTS.md
* Use Bun as package manager, test runner and main code runner.
* Use functional TypeScript.
* Prefer pure functions, immutability, and composition.
* Use `neverthrow` for all fallible operations.
* Never throw exceptions for application errors.
* Return `Result` / `ResultAsync`.
* Keep side effects at system boundaries.
* Prefer small, typed, composable functions.
